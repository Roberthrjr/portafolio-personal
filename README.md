# 👨‍💻 Mi Portafolio Personal (Versión 1.0)

¡Hola! Soy **Roberth Rios**, ex estudiante de Ingeniería de Sistemas en la Universidad César Vallejo (Trujillo). 

Este repositorio alberga mi **primer proyecto web personal**. Es el resultado de horas de estudio y práctica buscando dominar los fundamentos del desarrollo Frontend. Aquí no verás frameworks complejos, solo el poder de **HTML5 y CSS3 puro** en acción.

### 🚀 ¿Qué hay en este código?
Este proyecto representa mi esfuerzo por entender la arquitectura de la web:
* **Maquetación Semántica:** Uso correcto de etiquetas HTML (`header`, `section`, `article`).
* **Diseño Visual:** Estilos personalizados en CSS, definiendo mi propia paleta de colores.
* **Flexbox:** Implementación de cajas flexibles para la estructura (¡Adiós a los `floats`!).
* **Responsive Design:** Mis primeros pasos adaptando la web a diferentes pantallas.

### 🌟 Sobre Mí (En esta etapa)
Me defino como un desarrollador con **pasión por el aprendizaje constante**. Mi meta es automatizar procesos y convertirme en un experto desarrollador de aplicaciones. Cuando no estoy programando, disfruto salir a pasear o escuchar música.
